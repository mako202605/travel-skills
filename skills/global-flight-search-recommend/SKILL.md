# 全球航班查询与预订

> ⚡ **1次调用完成搜索→直飞中转分组→性价比标签→中转等待时间 · 中文城市名直输(100+城市) · 航司显示中文名 · 极省Token · 零配置即装即用**

---

## 快速入门

**3个开场白示例，复制即用：**
1. "北京到东京的航班" → 自动映射城市代码，展示直飞+中转
2. "上海飞三亚，6月15号，商务舱" → 指定日期和舱位
3. "浦东机场代码是什么" → 查机场代码

执行命令格式：

```
python SKILL_DIR/scripts/flight_search_recommend.py search --from-city "出发城市" --to-city "到达城市" --date "出发日期"
python SKILL_DIR/scripts/flight_search_recommend.py airport --keyword "搜索关键词"
```

其中 SKILL_DIR 替换为变量 CODEBUDDY_SKILL_DIR 的值。

## 【重要约束】

1. **必须调用真实API** — 通过云端代理查询RollingGo实时航班数据，绝不编造或缓存价格
2. **中文城市自动映射** — 100+城市支持中文直输（北京→BJS、东京→NRT），无需手动查代码
3. **航司显示中文名** — CA→国航、NH→全日空、EK→阿联酋，80+航司自动翻译
4. **直飞与中转分开展示** — 直飞优先展示，中转单独分组并显示等待时间
5. **性价比标签** — SmartValueScore≥80标🏆性价比之选
6. **禁止在不确定时编造价格** — 如无数据则明确告知，绝不虚构

2. **100+中文城市直输**：北京→BJS、东京→NRT、曼谷→BKK，自动映射

## 能力边界

**能做：**
- 搜索全球航班（国内+国际），返回实时价格

## 使用方式

### 搜索航班

```
python SKILL_DIR/scripts/flight_search_recommend.py search \
  --from-city "上海" \
  --to-city "东京" \
  --date 2026-07-15
```

### 搜索航班（指定舱位和往返）

```
python SKILL_DIR/scripts/flight_search_recommend.py search \
  --from-city "北京" \
  --to-city "曼谷" \
  --date 2026-07-15 \
  --ret-date 2026-07-20 \
  --cabin BUSINESS \
  --trip-type ROUND_TRIP
```

### 搜索机场/城市代码

```
python SKILL_DIR/scripts/flight_search_recommend.py airport --keyword "浦东"
```

### 参数说明

#### search 子命令

| 参数 | 必填 | 说明 |
|------|------|------|
| --from-city | ✅ | 出发城市，支持中文（如"北京"）或代码（如"BJS"） |
| --to-city | ✅ | 到达城市，支持中文（如"东京"）或代码（如"NRT"） |
| --date | ✅ | 出发日期 YYYY-MM-DD |
| --from-airport | ❌ | 出发机场代码（如PEK），精确指定机场 |
| --to-airport | ❌ | 到达机场代码（如NRT），精确指定机场 |
| --cabin | ❌ | 舱位：ECONOMY(默认)/BUSINESS/FIRST |
| --trip-type | ❌ | 行程：ONE_WAY(默认)/ROUND_TRIP |
| --ret-date | ❌ | 返程日期，往返时必填 |
| --adults | ❌ | 成人数量，默认1 |
| --children | ❌ | 儿童数量，默认0 |

#### airport 子命令

| 参数 | 必填 | 说明 |
|------|------|------|
| --keyword | ✅ | 搜索关键词，支持城市名、机场名、IATA代码 |
