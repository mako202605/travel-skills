# 上海迪士尼游园助手

零配置即装即用｜7项游园工具全覆盖｜含排队推荐和路线规划｜高德地图数据直连

专注上海迪士尼乐园的智能游园助手，为AI助手和旅行智能体提供实时排队、智能推荐、演出时间、路线规划等游园辅助能力。支持自然语言输入（如"带5岁孩子去迪士尼推荐下""现在排队多久""明天亲子一日游"），自动识别意图调用对应工具，返回结构化游园信息。

## 工具列表

| 工具 | 功能 | 参数 |
|------|------|------|
| disney_ticket | 门票价格查询 | date(日期), query(关键词) |
| disney_wait_times | 实时排队查询 | query(筛选条件，如"刺激""室内""亲子") |
| disney_show_schedule | 演出时间表 | query(筛选条件，如"必看""需预约") |
| disney_smart_next | 智能推荐下一步 | query(自然语言描述，如"带5岁孩子""刺激路线") |
| disney_route | 路线规划 | query(路线类型，如"亲子一日游""刺激路线") |
| disney_schedule | 营业时间查询 | days(天数，默认7，最大14) |
| disney_dining | 餐厅推荐 | query(筛选条件，如"梦幻世界餐厅""烧烤""便宜") |

- 工具 disney_ticket: primaryEnv=无, env=无
- 工具 disney_wait_times: 无额外环境变量
- 工具 disney_show_schedule: 无额外环境变量
- 工具 disney_smart_next: 无额外环境变量
- 工具 disney_route: 无额外环境变量
- 工具 disney_schedule: 无额外环境变量（营业时间数据通过高德地图代理获取）
- 工具 disney_dining: 无额外环境变量

## 数据流向

用户请求 → 本技能 → 高德地图SCF代理(营业时间查询) → 高德地图API
用户请求 → 本技能 → 本地数据(排队/演出/路线/门票/餐厅)

## 注意事项

- 排队时间为模拟数据，实际等待时间请以官方App为准
- 营业时间可能因节假日、特殊活动调整，请以官方公告为准
- 门票价格仅供参考，以官方实时价格为准
- 不提供购票服务，请通过上海迪士尼官方渠道购票

## 不能做

- 不能实时获取真实排队数据（官方未开放API）
- 不能在线购票或预约
- 不能查询酒店预订信息（可推荐搭配使用酒店搜索技能）
